QDII 场外基金监控 · 版本说明
=====================================

版本：v3.1
生成日期：2026-09-20
基线：v3.0（本包内所有 v3.0 功能全部保留）

如何确认你手上的是 v3.1（新版）
--------------------------------
1. 打开 qdii_nasdaq_sp500_monitor.html，页面最顶部三张指数卡片（纳斯达克100 / 标普500 /
   道琼斯）下方，应出现三张横排的**指数走势图**卡片，默认显示分时图，右上角有
   分时 / 日K / 月K / 年K 四个切换按钮，鼠标悬停图表可看该时点数值。
2. 展开「基金自助对比」→ 勾选基金 → 生成对比，走势图为新版视觉（平滑曲线、浅色细网格、
   胶囊区间按钮）；若所选基金跟踪纳斯达克100 / 标普500，图例中会**自动多出对应的
   虚线指数条目**（两者都选则两条都出现），鼠标悬停时图例数值随光标联动，
   移出后复位为区间末日值。
3. 展开「历史定投推演」并点「开始推演」，曲线随进度**逐段生长、走到哪画到哪**
   （不再出现结局曲线提前显示的残影）；动画明显变慢，播放中鼠标悬停可查看任意日期的
   账户市值 / 累计投入 / 浮动盈亏 / 收益率 / 已持有天数，按住可左右拖动，移出后自动续播。
4. scan.py 文件大小约 162 KB（v3.0 为 130 KB）
5. data 文件夹里新增 idx_trend.json（约 38 KB）

v3.1 相比 v3.0 的四处变化
--------------------------------
1. 页首指数走势图（新增）
   - 三标的横排（3 列等宽，自适应单列），单张卡片约 1/3 内容宽 × 约 175 px 高，
     三张合计约占一整行，未挤占下方内容。
   - 分时图为当日逐分钟（391 点）；日K 保留最近 120 根；月K / 年K 由日线聚合
     （72 / 13~23 根），涨跌红绿按 A 股习惯着色。
   - 分时图带昨日收盘基准虚线，日K 为蜡烛图（影线 + 实体），月K / 年K 为收盘折线 + 末值点。
   - 数据源：分时走腾讯行情（qt.gtimg.cn，usNDX / usINX / usDJI），日线走新浪财经
     日K 接口；缓存 data/idx_trend.json，40 分钟内复用，抓取失败自动沿用旧缓存。
2. 对比走势图自动叠加指数（新增）
   - 勾选基金中只要出现跟踪纳斯达克100 的基金，即在走势图上叠加纳指100 走势；
     出现标普500 基金则叠加标普500；两者都有则两条都叠加（纳指100 在前）。
   - 叠加线条为虚线、空心末点，图例标注「叠加指数」；口径为价格指数、未含汇率与费率，
     与基金累计净值涨跌幅同起点归一为 0%，页面脚注已注明。
   - 仅跟踪「纳斯达克科技 / 生物科技 / 精选（主动）/ 标普500等权重」的基金不触发叠加。
3. 对比走势图视觉重做（Marvis / Apple 风）
   - 曲线改为平滑样条，单一基金时加同色渐变面积；网格改浅色细线，零轴用短虚线强调；
   - 区间按钮改为胶囊样式，图例改为色块 + 名称 + 代码 + 区间涨跌的横向卡片；
   - 悬停 / 按住拖动查看任意日期，提示卡按数值降序排列、超 16 只折叠提示。
4. 定投推演走势图视觉重做 + 动画修复
   - 同一套 Marvis / Apple 视觉（平滑曲线、渐变面积、浅色网格、末值点）。
   - 修复「结局曲线提前显示」：改为裁剪窗口（clipPath）控制可见进度，曲线本体始终是
     完整路径，播放时只露出一段，起点可见宽度为 0。
   - 新增悬停查看任意日期的账户数据与按住拖动交互；拖动 / 悬停时暂停，移出后自动续播。
   - 动画时长由原来的固定短时长改为按数据量 3.6~9 秒自适应（明显变慢），
     仍保留「跳过动画 / 重播」，并尊重系统「减少动态效果」偏好。

沿用 v3.0 已有内容
--------------------------------
- 两个模块折叠化、推演过程动画、对比筛选 + 加宽列表 + 申购状态徽标、业绩走势图区间切换、
  95 只基金监控、公告栏提取、变动历史日志、仅变动发邮件、GitHub Actions 云端运行。

运行方式（不变）
--------------------------------
- 手动：在本目录执行 python scan.py（可选 --hist 强制刷新历史行情 / 净值序列 / 指数走势，
  指数走势默认 40 分钟内复用缓存）
- 页面：生成的 qdii_nasdaq_sp500_monitor.html 为自包含单文件，双击即可查看
- 定时：沿用 run_daily.bat / run_daily.sh 与《每日自动运行说明.md》

注意事项
--------------------------------
- data/mail_config.json 含 SMTP 授权码明文，上传 GitHub 前请勿提交（包内已附 .gitignore）。
- 指数走势与基金净值均为历史行情，不代表未来收益；本工具不构成投资建议。
